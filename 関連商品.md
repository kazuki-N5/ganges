# 関連商品表示（ジャンル別おすすめ順取得）確定仕様書

> [!NOTE]
> 使用するFlutterパッケージ（`Dio`, `hooks_riverpod`, `url_launcher`,
> `cached_network_image`
> 等）や全体の技術スタック・アーキテクチャについては、[アプリ.md](file:///c:/Users/kazuk/program/AppList/ganges/%E3%82%A2%E3%83%97%E3%83%AA.md)
> を参照してください。

本ドキュメントは、商品詳細画面で「カートに入れる」ボタンを押した際に表示されるボトムシート（「この商品とよく一緒に購入されている商品」）において、**「商品のジャンルID
(`genreId`) を使用した楽天おすすめ順 10件取得」**
処理を適用するための確定仕様書です。

---

## 1. 確定仕様概要

- **方式**: **「ジャンルID指定 ＋ 楽天市場おすすめ順 (`sort: 'standard'`)
  取得」**
- **理由・メリット**:
  - 商品タイトルに含まれるノイズ（例: `「10kg」「令和7年産」「セール」`
    等）に影響されず、お米ならお米、マイクならマイクの関連商品が **100%確実に**
    表示される。
  - 楽天市場公式のおすすめ順アルゴリズム (`sort: 'standard'`)
    に基づくため、適度に安定しつつ自然なおすすめ商品が10件並ぶ。
  - 自分自身がリストに含まれる場合は `itemCode != currentProduct.itemCode`
    で自動的に重複排除する。

---

## 2. APIリクエスト仕様

- **エンドポイント**:
  `https://openapi.rakuten.co.jp/ichibams/api/IchibaItem/Search/20260701`（または標準Search
  API）
- **パラメータ**:
  - `genreId`: カートに追加された商品の `genreId`（例: `201184`）
  - `sort`: `'standard'`（楽天おすすめ順）
  - `hits`: `10`

---

## 3. 実装コード例

### ① `RakutenApiClient` へのジャンル検索メソッド追加 (`rakuten_api_client.dart`)

```dart
/// ジャンルIDを指定して楽天おすすめ順で商品を取得
Future<List<Product>> getProductsByGenre({
  required String genreId,
  int hits = 10,
}) async {
  if (useMockOnly || genreId.isEmpty) {
    return getRankingProducts(hits: hits);
  }

  try {
    final response = await _dio.get(
      _searchBaseUrl,
      options: Options(headers: {'Origin': 'https://example.com'}),
      queryParameters: {
        'applicationId': _appId,
        if (_accessKey.isNotEmpty) 'accessKey': _accessKey,
        if (_affiliateId.isNotEmpty) 'affiliateId': _affiliateId,
        'format': 'json',
        'genreId': genreId,
        'sort': 'standard',
        'hits': hits,
      },
    );

    if (response.statusCode == 200 && response.data != null) {
      final List items = response.data['Items'] ?? [];
      return items.map((item) => Product.fromRakutenJson(item)).toList();
    }
  } catch (e) {
    // 通信エラー時はランキングAPIへフォールバック
  }

  return getRankingProducts(hits: hits);
}
```
